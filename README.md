# Customer Churn Prediction
Project Overview

This project builds a machine learning model to predict customer churn and uncover the key factors driving customer retention. Beyond prediction, the focus is on translating data into actionable business insights that can improve customer lifetime value.

## Key Highlights
Built an end-to-end churn prediction pipeline (data cleaning → modeling → evaluation)
Identified pricing and tenure as primary drivers of churn
Applied feature importance analysis to translate model output into business strategy
Demonstrated ability to connect technical results with real-world decisions

## Problem Statement

Customer churn directly impacts revenue and growth. The goal of this project is to:
- Predict which customers are likely to churn
- Understand why they churn
- Provide insights to support data-driven retention strategies

## Approach
1. Data Preparation
- Cleaned and preprocessed raw data
- Converted data types and handled missing values
- Encoded categorical variables for machine learning
2. Exploratory Data Analysis
- Analyzed churn distribution and feature relationships
- Identified early signals in pricing and tenure trends
3. Model Development
- Split data into training and testing sets
- Trained a classification model (e.g., Random Forest / Logistic Regression)
- Focused on balancing performance and interpretability
4. Evaluation
- Assessed model using:
- Accuracy
- Precision & Recall
- F1 Score
5. Feature Importance
- Ranked features based on influence on predictions
- Translated technical output into business insights

## Key Insights
- Pricing is the strongest driver of churn
Customers with higher monthly and total charges are more likely to leave
- Customer tenure significantly impacts retention
New customers have higher churn risk, while long-term customers are more stable
- Contract type influences commitment
Month-to-month customers show higher churn compared to long-term contracts
- Support services add moderate value
Features like Tech Support and Online Security contribute to retention but are secondary drivers

## Business Impact
This analysis suggests that churn can be reduced by:
- Optimizing pricing strategies for high-risk customers
- Strengthening early-stage customer engagement
- Incentivizing long-term contracts
- Enhancing perceived value through bundled services

Churn is primarily driven by financial factors and customer lifecycle stage. By aligning business strategies with these insights, organizations can improve retention and maximize long-term revenue.
